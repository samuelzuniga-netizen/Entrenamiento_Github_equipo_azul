# Problema
El tráfico de la ciudad sigue ciertos patrones durante el día.
# Datos
{
  "8:00": "alto",
  "9:00": "alto",
  "10:00": "medio",
  "11:00": "bajo"
}
# Reto
Detectar el patrón y decidir cuál es el mejor momento para moverse por la ciudad.
# Respuesta
- Mientras va pasando el dia, el trafico va bajando.
- El mejor momento del dia para moverse a la ciudad es a las 11:00
