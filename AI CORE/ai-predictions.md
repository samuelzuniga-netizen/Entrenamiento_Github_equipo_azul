#### PROBLEMA
Ahora el sistema debe clasificar nuevos emojis.

### DATOS
Casos de prueba: 😃, 😤, 😐

### RETO
Predecir si cada emoji es positivo o negativo usando su modelo.

### SOLUCION
Modelo: 
- Sonrisa hacia arriba es igual a positivo
- Gesto de labios hacia abajo negativo 
- Gesto de fruncir de las cejas negativo 

- 😃 => positivo
- 😤 => negativo 
- 😐 => negatibo
