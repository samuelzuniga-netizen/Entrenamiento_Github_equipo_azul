### PROBLEMA
El sistema necesita aprender a clasificar emociones.

### DATOS
[
  {
    "emoji": "🙂",
    "sentiment": "positivo"
  },
  {
    "emoji": "😭",
    "sentiment": "negativo"
  },
  {
    "emoji": "😡",
    "sentiment": "negativo"
  },
  {
    "emoji": "😎",
    "sentiment": "positivo"
  }
]
### RETO
Encontrar el patrón que separa emociones positivas de negativas.

### SOLUCION
- Sonrisa hacia arriba es igual a positivo
- Gesto de labios hacia abajo negativo 
- Gesto de fruncir de las cejas negativo
